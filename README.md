YBX. Young Box Office is a website which uses "Big Data" to find
what are the best movies small cinemas can run to get the most youth towards their cinema.
SETUP:
Add own credentials to ApiKeyExample.php API key can be retrieved from https://www.omdbapi.com/apikey.aspx.
Put your own data in the folder /Data/ with the name being year-week (Ex: 25-38.csv) file type csv.
